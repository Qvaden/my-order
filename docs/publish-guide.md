# Руководство по публикации сервиса в каталоге VK Mini Apps

Пошаговая инструкция для владельца приложения по загрузке материалов и прохождению модерации ВКонтакте.

---

## Шаг 1. Подготовка публичной ссылки на Политику конфиденциальности

Перед отправкой заявки модераторы VK требуют указать действующую ссылку на Политику конфиденциальности:
1. Откройте файл `docs/privacy-policy.md`.
2. **Вариант А (рекомендуемый):** Опубликуйте текст в вашем сообществе ВКонтакте в виде **VK Статьи** (Инструмент «Статьи» в группе ВКонтакте). Скопируйте полученную ссылку вида `https://vk.com/@clubXXXXX-privacy-policy`.
3. **Вариант Б:** Разместите файл на GitHub Pages или любом статическом веб-сервере.

---

## Шаг 2. Вход в кабинет разработчика VK

1. Перейдите по адресу: [dev.vk.com/management/apps](https://dev.vk.com/management/apps).
2. Выберите ваше приложение **«Мой Порядок»** (или нажмите «Создать приложение», тип: **VK Mini App**).
3. Перейдите во вкладку **«Настройки»**.

---

## Шаг 3. Заполнение метаданных и информации о приложении

В разделе **«Информация»** вставьте данные из файла `docs/publish-texts.md`:

| Поле в кабинете VK | Значение для ввода |
| :--- | :--- |
| **Название** | `Мой Порядок: Платежи и Дела` |
| **Краткое описание** | `Платежи, счётчики, документы и дела в одном месте. Без подписок для базы.` |
| **Категория** | `Утилиты` (или `Сервисы`) |
| **Возрастное ограничение** | `0+` |
| **Описание** | Вставьте полный текст из раздела 2 файла `docs/publish-texts.md` |
| **Политика конфиденциальности** | Вставьте ссылку, подготовленную на Шаге 1 |
| **Сообщество приложения** | Выберите ваше официальное сообщество ВКонтакте |

---

## Шаг 4. Загрузка графических ассетов

Все подготовленные графические файлы находятся в папке `assets/publish/`:

1. **Иконка сервиса (512×512):**
   - Загрузите файл: `assets/publish/icon-512.png`.
   - Проверьте, как иконка отображается в круглой и квадратной маске предварительного просмотра.
2. **Обложка для каталога (1200×628):**
   - Загрузите файл: `assets/publish/cover-1200x628.png`.
   - Убедитесь, что текст заголовка находится в безопасной центральной зоне.
3. **Скриншоты интерфейса (750×1334):**
   - Перейдите в блок «Скриншоты».
   - Загрузите по порядку файлы из папки `assets/publish/screenshots/`:
     1. `screenshot-1-home.png` — Главный экран с виджетами и быстрыми действиями.
     2. `screenshot-2-payments.png` — Учёт платежей и квитанций с фильтрами.
     3. `screenshot-3-stats.png` — Расширенная аналитика и прогноз расходов PRO.
     4. `screenshot-4-family.png` — Семейный доступ и совместный бюджет.
     5. `screenshot-5-dark-theme.png` — Премиальная тёмная тема и фиолетовый акцент.

## Шаг 5. Настройка монетизации (PRO-подписка)

1. В боковом меню выберите пункт **«Платежи»** / **«Подписки»**.
2. Включите приём платежей через **VK Pay / Голоса**.
3. Создайте тариф подписки:
   - **Название:** `PRO на 1 месяц`
   - **Стоимость:** `99 ₽` (или эквивалент в Голосах)
   - **Период:** 1 месяц с автопродлением
4. Создайте годовой тариф:
   - **Название:** `PRO на 1 год`
   - **Стоимость:** `799 ₽`
   - **Период:** 1 год

---

## Шаг 6. Самопроверка по чек-листу

Откройте `docs/moderation-checklist.md` и последовательно пройдитесь по каждому пункту. Убедитесь, что:
- Приложение открывается по HTTPS без ошибок консоли.
- В интерфейсе нет намёков на обязательную платность (бесплатный тариф полностью рабочий).
- В мобильном приложении VK (iOS / Android) интерфейс открывается корректно.

---

## Шаг 7. Отправка на модерацию

1. В верхней панели кабинета приложения найдите статус **«В разработке»**.
2. Нажмите кнопку **«Отправить на модерацию»** (или «Подать заявку в каталог»).
3. В поле комментария для модератора укажите:
   ```text
   Здравствуйте!
   Сервис «Мой Порядок» — утилита для удобного ведения бытовых платежей, показаний счётчиков, документов и дел.
   Все базовые функции полностью бесплатны и доступны офлайн через IndexedDB.
   PRO-подписка предоставляет расширенные функции (облако, семейный доступ, аналитику, PDF).
   Для проверки PRO-функционала можно воспользоваться тестовым режимом VK Pay или переключателем в настройках.
   Спасибо!
   ```
4. Нажмите **«Подтвердить»**.

---

## Шаг 8. Ожидание и обработка замечаний

- Срок первичного рассмотрения модераторами: **от 1 до 3 рабочих дней**.
- Уведомление о решении придёт в личные сообщения от официального бота «Разработчики ВКонтакте» и на email.
- **Если одобрено:** статус автоматически сменится на «Одобрено», приложение станет доступно в каталоге сервисов VK.
- **Если есть замечания:** модератор подробно напишет причину. Обычно это мелкие нюансы (например, уточнить текст ссылки или скорректировать формулировку). Внесите правку и нажмите «Повторно отправить».
