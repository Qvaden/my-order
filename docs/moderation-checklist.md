# Чек-лист модерации VK Mini Apps: «Мой Порядок»

Данный чек-лист составлен на основе официальных правил платформы **VK Mini Apps** и требований к каталогу сервисов ВКонтакте (**dev.vk.com**). Заполните все пункты перед отправкой заявки на модерацию.

---

## 1. Техническая готовность и стабильность

- [x] **Протокол HTTPS:** Сервис загружается и стабильно работает исключительно по защищённому протоколу HTTPS. Отсутствуют mixed-content предупреждения.
- [x] **Инициализация VK Bridge:** Вызов `vkBridge.send('VKWebAppInit')` происходит сразу при старте приложения без задержек.
- [x] **Чистая консоль разработчика:** В консоли браузера (`DevTools`) при проходе по всем разделам (`#home`, `#payments`, `#meters`, `#documents`, `#tasks`, `#stats`, `#backup`, `#subscription`) нет необработанных исключений (`uncaught errors`) и критических `warning`.
- [x] **Офлайн-режим (PWA/Service Worker):** Приложение кэширует статические ресурсы через Service Worker (`sw.js`) и сохраняет работоспособность при временной потере сети.
- [x] **Время первой загрузки:** Интерактивность первого экрана (`Time to Interactive`) составляет менее 1.5–2 секунд на мобильных сетях 3G/4G.
- [x] **Отсутствие внешних CDN, блокируемых в РФ:** Все скрипты, шрифты и стили загружаются локально либо из доверенных источников.

---

## 2. Интерфейс и пользовательский опыт (UI/UX)

- [x] **Мобильная адаптивность:** Интерфейс корректно подстраивается под экраны от 320px до десктопных мониторов.
- [x] **Безопасные зоны (Safe Areas):** Учтены отступы мобильных устройств (`viewport-fit=cover`, верхняя шторка, закруглённые углы и системная полоса жестов снизу).
- [x] **Навигация:** Нижний таббар (Bottom Navigation Bar) всегда доступен, активные вкладки подсвечиваются, переходы по экранам происходят плавно.
- [x] **Поддержка тем оформления:** Сервис поддерживает системную светлую и тёмную темы, а также синхронизирует тему с клиентом VK (`VKWebAppUpdateConfig`).
- [x] **Читаемость и масштаб:** Текст легко читается, минимальный размер шрифта не менее 13px, интерактивные области кнопок не менее 44x44px.
- [x] **Пустые состояния (Empty States):** В разделах с отсутствующими данными показаны аккуратные иллюстрации и подсказки, побуждающие создать первую запись.

---

## 3. Требования к контенту и функционалу

- [x] **Базовый функционал без ограничений:** Пользователь может полноценно вести учёт платежей, счётчиков, документов и дел на бесплатном тарифе (Free) без ограничения по времени.
- [x] **Отсутствие обязательной регистрации:** Вход в приложение не требует ввода логина/пароля или номера телефона; данные сохраняются локально.
- [x] **Отсутствие запрещённого контента:** В сервисе нет азартных игр, алкоголя, табака, микрозаймов, эротики, ставок и политической агитации (соответствует маркировке `0+`).
- [x] **Корректность русского языка:** Все заголовки, кнопки, подсказки и системные сообщения написаны грамотно, без орфографических и пунктуационных ошибок.

---

## 4. Монетизация и PRO-подписка

- [x] **Прозрачность цен:** Стоимость подписки указана явно: **99 ₽/мес** или **799 ₽/год**. Нет скрытых списаний.
- [x] **Соответствие правилам платежей VK:** Оплата подписки осуществляется через официальные методы платформы (`VKWebAppShowSubscriptionBox` / VK Pay).
- [x] **Чёткое разделение Free и PRO:** Бесплатные функции не блокируются. Пользователю наглядно показано, какие именно преимущества даёт PRO (облачный бэкап, семейный доступ, экспорт PDF, аналитика, PIN-код).
- [x] **Тестовый режим платежей:** Проверена работа в песочнице VK Bridge, ошибки отказа пользователя от покупки обрабатываются мягко, без зависаний интерфейса.

## 5. Графические ассеты для каталога

- [x] **Иконка 512x512px (`icon-512.png`):**
  - Разрешение ровно 512x512 px, формат PNG;
  - Отсутствует прозрачность (сплошной фон бренда);
  - Логотип отлично различим в миниатюре 48x48 px;
  - Отсутствуют мелкие нечитаемые надписи.
- [x] **Обложка каталога 1200x628px (`cover-1200x628.png`):**
  - Разрешение ровно 1200x628 px (соотношение ~1.91:1);
  - Название приложения «Мой Порядок» и девиз читаются на любом экране;
  - Важные элементы не заходят на края (безопасное поле не менее 40px).
- [x] **Скриншоты интерфейса (от 3 до 8 шт.):**
  - Разрешение: **750x1334 px** (соотношение 9:16);
  - **Без рамок телефонов и мокапов** (строго реальный снимок экрана согласно правилам VK);
  - Заполнены реалистичными русскоязычными данными (не тестовые "asdf" или "Lorem ipsum");
  - Отражают ключевые возможности: Главный экран, Платежи, Аналитика PRO, Семейный доступ, Тёмная тема.
